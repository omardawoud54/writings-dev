# Writing.dev

Writings.dev is a landing page website challenge came from [roadmap.sh in figma](https://www.figma.com/file/nh0V05z3NB87ue9v5PcO3R/writings.dev?type=design&node-id=0%3A1&t=2iQplaIojU3ydAfW-1)

## About the Project

A website that has programming blogs for developers

### Why I made this website

I wanted to make this website to enhance my HTML, CSS, and my new technical skill Sass and to see if I can make a website after taking the courses

## Tech Stack

HTML5, CSS, SASS, CSS Flexbox/Grid

## What I did

I made a website that is responsive to diffrent devices and I use Sass for more performance to CSS and I segment Sass into files that are organized and I made some transitions like the cards, buttons and more

## What I learned

I learned how I organize my files especially on Sass and tried the features on sass that I learned from it like variable, ``@import``, nesting, ``@mixin`` and more and I learned how I make a horizontal scrollable in the tags
